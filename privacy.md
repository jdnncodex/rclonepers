# Privacy Policy — GMKtec rclone

**Last updated:** 25 October 2026

## Overview

GMKtec rclone is a personal, non-commercial integration used to connect a privately operated Linux home server to the owner's Google Drive account.

The integration uses the open-source rclone software and Google OAuth 2.0.

## Google Drive Access

The application may access, download, upload, organise and manage files in the Google Drive account authorised by the owner.

Access is used exclusively for personal file management, encrypted storage, backups and media streaming.

## Data Storage and Security

Google OAuth credentials and access tokens are stored locally on the owner's server in rclone's configuration.

Files encrypted using rclone crypt are encrypted locally before being uploaded to Google Drive.

The application does not intentionally transmit Google Drive files or OAuth credentials to unrelated third-party services.

## Data Sharing

This integration is intended for personal use and is not offered to other users.

The operator does not sell Google Drive data or use it for advertising.

## Data Retention and Revocation

Files remain in Google Drive until managed or deleted by the account owner.

The owner can revoke the application's access through Google Account security settings and remove locally stored credentials.

## Website

This informational website does not include a custom analytics or tracking system. GitHub Pages, as the website hosting provider, may process technical visitor information under its own policies.

## Contact

Privacy questions can be directed to the operator through the project's GitHub repository.
